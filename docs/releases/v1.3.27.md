# Excel Sheet Merger — 실패 후 임시 XML·파일 핸들 정리

- CSV·Excel 읽기나 저장이 실패한 뒤 시스템 TEMP 폴더에 남던 **해당 작업 소유의 openpyxl 시트 XML 파일**을 정리합니다. 다른 실행 중인 통합문서나 사용자 파일은 삭제하지 않습니다.
- 손상된 XLSX를 읽는 중 오류가 발생해도 입력 파일 핸들을 닫습니다. 오류와 traceback이 보관되는 경우에도 파일이 계속 열려 있지 않도록 합니다.
- 디스크 부족 등으로 XLSX 저장이 실패하면 출력 ZIP 핸들과 시트 XML을 정리합니다. 정리 중 오류가 나더라도 최초 실패 원인은 유지합니다.
- CSV·XLSX·XLSM·XLS 지원, 시트명, 수식·서식, 그룹 체크박스, 결과 파일명 자동 번호 부여, 원본 보호와 UI는 유지합니다. 기존 ZIP 안전 한도는 완화하지 않았습니다.
- 신규 회귀 테스트 11개: 입력 실패, 정상·스트리밍 저장 실패, 다른 작업 파일 보존, 반복 실패 후 재실행, ZIP 내부 XML 동등성 등.
- 로컬 핵심 테스트 29개 통과, XML 백엔드 2종에서 신규 테스트 통과. 전체 Windows 테스트·EXE 스모크는 이 Release에 연결된 GitHub Actions 기록을 기준으로 확인하세요.
- 회사 Windows 11·DRM·SMB 환경의 8시간 장시간 테스트는 아직 수행하지 않았습니다. 강제 프로세스 종료나 운영체제가 삭제를 거부하는 상황까지 정리를 보장하지 않습니다.
