# Minimal Office UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox syntax.

**Goal:** Apply approved minimalist white/green Windows 11 UI to Excel Sheet Merger without changing existing CSV merging behavior, and publish a validated Windows EXE Release.

**Architecture:** Preserve the existing `MergeApp` class, `ttk.Treeview`, `ScanReport`, background-thread events and `merge_group` API. Introduce a dedicated `ui_theme.py` for ttkbootstrap-backed style with a Tk `clam` fallback for development environments where the optional UI package cannot be installed, and reorganize `gui.py` into header, folder, summary metrics, preview, collapsible log, fixed action footer. Package the dependency with PyInstaller and verify using Windows GitHub Actions.

**Tech Stack:** Python 3.12+, tkinter/ttk, ttkbootstrap 2.2.6, openpyxl, unittest, PyInstaller, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-28-minimal-office-ui-design.md` (approved on GitHub at `sebia1993/Excel-Sheet-Merger`).

## Global Constraints

- Never edit `src/excel_sheet_merger/classify.py` or `src/excel_sheet_merger/merge.py`.
- Preserve `MergeApp`, `run_app`, `summarize_scan`, `_selected_groups`, `_start_merge`, `_worker_merge`, `_process_group`, `_consume_events` existing contracts, including direct construction via `MergeApp.__new__` in the current tests.
- Preserve CSV encoding, time-named sheets, site/day grouping, input files, non-overwrite, corrupt-CSV group failure semantics, and log output.
- Maintain Windows EXE single-file, no Python/Excel install on user PC.
- Prevent thread affinity violations; mutate Tk widgets only on main thread.
- Keep light theme only; no DnD, dark mode, or remote API.
- This turn explicitly authorizes implementation and publishing a new GitHub Release after successful verification.

## Review Focus

- Small 900x640 window: action buttons and tree remain reachable.
- Multi-group selection: selected child row still selects entire parent group.
- Worker exceptions: auto-expanded log and accurate final success/fail/skip metrics.
- Theme resources: Windows PyInstaller collects ttkbootstrap resources and startup does not fail on missing assets.
- Existing CSV behavior: three time-named sheets preserve cell strings including IDs and formula-looking content.
