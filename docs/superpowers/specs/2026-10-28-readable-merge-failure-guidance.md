# Excel Sheet Merger — 실패 원인 및 해결 안내 설계

> **승인 맥락:** 사용자가 Superpowers로 프로그램 안에 파일별 병합 실패 원인과 조치 방법을 표시하고, 문서보안 처리 파일에서 관찰되는 CP949 오류를 설명하도록 요청함.
> **2026-10-28 / 기준:** 공개 GitHub `sebia1993/Excel-Sheet-Merger` v1.3.9.

## 목적

현재 처리 로그는 예외 문자열을 보여 주지만 완료 팝업은 `실패 1개`만 보여 주어 비개발자에게 도움되지 않는다. 파일별 실패 원인·권장 조치를 한국어로 제공하면서 기존 CSV/Excel 변환 결과, 원본/기존 결과 보존 및 부분 실패의 독립 처리를 유지한다.

## 원인 검증과 보안 문서 정확도

- CSV는 UTF-8 전체 판독 실패 시 CP949로 읽는다. CP949 UnicodeDecodeError의 의미는 **해당 바이트가 CP949로 해독되지 않는다**는 것뿐이다. 보안 프로그램 암호화와 손상/다른 인코딩 모두 가능하다. 암호화 단정 금지.
- 사용자가 보안 프로그램으로 보호된 문서를 사용하는 경우, `문서보안 적용 가능성`을 명시한다. 권장 조치는 **승인된 방식으로 정상 열람 가능한 원본/사본을 준비하거나 보안 관리자에게 문의**하는 것뿐이다. 복호화 우회, 보안 해제 자동화 금지.
- 일반적인 UTF-8/CP949 CSV 정상 처리 계약을 바꾸지 않는다. 일괄 인코딩 강제 변환이나 `errors=ignore` 사용 금지.

## 설계 대안

1. 기존 팝업과 작업 기록만 개선: 최소 개발이나 실패 후에도 원인이 접히거나 UI에 남지 않을 수 있다.
2. **팝업 + 접이식 작업 기록 + 화면 내 실패 안내 배너 (채택):** 실행 후에도 파일명/이유/조치를 화면에서 확인 가능. 화면 추가 영역은 실패한 경우에만 노출한다.
3. 별도 실패 전용 창/탭: 클릭 수와 복잡성이 늘어난다.

## 사용자 표시

- 실패한 파일명, 실패 제목(예: `CSV 문자 인코딩 오류`), 가능한 원인, 조치 방법.
- 예시: `A사업장_20261028_14시.csv` — `CSV 문자 인코딩 오류` — `파일의 데이터를 CP949로 해석할 수 없습니다. 문서보안으로 보호되었거나 인코딩/형식이 맞지 않을 수 있습니다. 이 오류만으로 암호화 여부는 확정할 수 없습니다.` — `사내 보안 정책에 따라 열람 권한이 있는 프로그램에서 정상 CSV/Excel로 내보낸 뒤 다시 시도하거나 문서보안 담당자에게 문의하세요.`
- 권한/경로/빈 파일/시트 개수 오류도 구체적인 조치 제시. 분류 불가능한 오류는 `원인을 특정하지 못했습니다. 작업 기록의 상세 오류를 관리자에게 전달하세요.`
- 여러 실패 시 완료 팝업에는 최대 3개 상세 요약 + 나머지 개수, 화면 안내 배너에는 최근 실패와 누적 건수, 펼친 로그에는 모든 실패를 기록.
- 분석 재실행과 병합 시작 시 이전 실패 표시 초기화; 일부 실패 시 다른 그룹 계속 처리.
- 모든 UI 변경은 Tk 메인 스레드에서, 작업 스레드는 큐 이벤트와 UTF-8-BOM 로그 파일만 기록.

## 기술 계약

- `merge.py`: 입력 처리에 오류가 발생하면 **원래 예외 내용 보존** 및 실패한 `SheetInput` 경로를 `SourceFileError`에 추가해 올린다. 오류 설명 분류 로직은 병합 엔진 밖의 별도 모듈로 분리한다.
- `failure_guidance.py`: 예외 원인 체인을 검사하고 한국어 `FailureGuidance`(파일명, 제목, 원인, 조치, 기술 상세) 제공. 기술 오류는 로그로만 보여 준다.
- `gui.py`: `failure` 큐 이벤트를 받으면 배너 자동 표시 및 로그 펼침; 완료 대화창에 원인/조치 반영. 기존 `done` 이벤트 형태와 그룹 선택/처리 수 유지.
- 파일/그룹 원본 데이터, 파일명 규칙, 시간별 시트명, 기존 결과에 `(2)/(3)` 붙이기, 서식 처리, EXE 패키징 계약 유지.

## 수용 테스트

1. 실제 잘못된 CP949 바이트의 CSV에서 정확한 원본 파일명과 보안 문서 **가능성 및 비확정성**, 승인된 조치 안내.
2. 정상 CP949 한글 CSV 병합은 그대로 성공.
3. 엑셀의 비정상 형식 및 원본 다중 시트는 알맞은 원인·조치 표시; CP949로 오분류하지 않음.
4. 파일 미존재/권한 문제는 권장 조치 표시; 오인 암호화 단정 방지.
5. 여러 그룹 가운데 하나 실패 시 나머지는 저장하고 오류 배너/팝업/로그가 누락 없이 설명.
6. 재분석 또는 새 작업 시 오래된 실패 설명이 남지 않고, GUI 큐/타이머/체크박스가 정상.
7. 전체 테스트 및 Windows GitHub Actions 성공, 최신 EXE 릴리즈 실재 확인.
