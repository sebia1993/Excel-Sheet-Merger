# CSV 입력 → 시간별 시트 XLSX 변환 설계

## 목표
Windows 11에서 Python 설치 없이 EXE를 실행하여, 사업장·날짜가 같은 시간별 CSV 파일을 하나의 XLSX 통합문서로 안전하게 만든다. 각 CSV의 데이터는 서로 다른 시간 이름의 시트에 들어간다.

## 요구사항
- 기존 프로그램의 파일명 분류 규칙, 미리보기, 사업장·날짜별 구분, 중복 시간 처리, 단독 파일 제외, 결과 덮어쓰기 방지를 유지한다.
- 입력은 Excel 내보내기 CSV(`*.csv`)이며, 동일 시간의 파일은 `11시`, `11시 (2)`로 고유 시트명을 갖는다. 시간순 정렬한다.
- 결과는 `병합결과/A사업장_20261028.xlsx`, 내부 시트는 `11시`, `14시`, `17시` 형식이다.
- Excel COM/설치가 필요하지 않다. Python 표준 `csv`로 CSV를 파싱하고 `openpyxl`로 `xlsx`를 쓴다.
- UTF-8(BOM 유무), CP949/EUC-KR, UTF-16(BOM) 입력을 읽을 수 있어야 한다. 깨진 CSV는 실패 로그에 기록하고 결과 XLSX를 생성하지 않는다. CSV 쉼표+따옴표+줄바꿈 지원.
- 데이터 원형 보존을 위해 모든 값은 문자열로 기록한다. `00123`, `=1+1`도 수식 또는 숫자로 바꾸지 않는다. 원본 CSV 변경 금지.
- CSV 데이터가 빈 파일이거나 Excel 행/열/셀 길이 제한을 넘거나 Excel에서 사용할 수 없는 문자를 포함하면 그룹 처리를 실패시킨다.
- 임시 파일에 완성 후 원자적으로 확정하고 기존 결과는 덮어쓰지 않는다. 실패 후 임시 파일 정리, 다음 그룹 처리는 계속한다.
- GUI는 CSV를 명시하고 Excel 설치가 필요 없음을 알린다. 작업 진행/성공/실패/제외 사유를 기록한다.
- Windows 11 x64 GitHub Actions CI: Python 테스트, PyInstaller EXE 생성, PE/SHA256 검사, 새 GitHub Release 게시.

## 구현 선택
- CSV를 엑셀 COM으로 열고 복사하는 방법은 Office 설치가 필요하고 CSV 원형에 타입 변환이 발생할 수 있어 제외한다.
- 단일 워크북은 `openpyxl.Workbook(write_only=True)`로 구성하고 CSV 스트리밍으로 처리한다.
- 원본 CSV 값은 모두 텍스트로 고정하며, 데이터 형식 자동 추정과 스타일은 범위 밖이다.
- 추후 실제 업무 파일명의 특수 규칙은 샘플 확보 시 별도 개선한다.

## 검증
- 분류, 시간별 시트명, UTF-8/CP949 인코딩, 쌍따옴표 안 쉼표/줄바꿈, 식별자/수식 리터럴, 실패 원자성, 중복파일 보호, GUI-병합 경로에 대해 자동 테스트.
- Windows CI에서 EXE 패키지 생성까지 확인. GUI 실사용은 후속 현장 검증 대상.
