# Excel Sheet Merger — 그룹별 체크박스 선택 디자인

작성일: 2026-10-28. 상태: 승인된 A안 구현. 기준: Excel Sheet Merger v1.3 코드(7333427), Windows 11 Tkinter/ttkbootstrap GUI.

## 목표

사용자가 여러 병합 그룹을 Ctrl/Shift 없이 직관적으로 지정하고, 체크한 그룹만 선택 병합한다. 기존 **전체 그룹 병합**은 모든 병합 가능 그룹에 작동하며 기존 CSV/Excel 파일 분류·병합 및 원본 보호는 바꾸지 않는다.

## 접근법

- A(선택): 현재 Treeview의 부모 그룹 행에 표시용 체크박스(☐/☑)를 넣고, 선택 상태를 별도 집합으로 관리. 전체 선택/해제와 키보드 Space 조작을 제공한다. 기존 위젯과 미리보기·빌드 구조를 유지할 수 있다.
- B(제외): Treeview 옆에 실제 Checkbutton을 각 행과 동기화. 스크롤·접기·행 높이·DPI 정렬이 까다롭다.
- C(제외): 새로운 표 위젯으로 완전 교체. 외부 의존성을 늘리고 안정적인 기존 미리보기를 바꿔야 한다.

## 인터랙션 계약

1. `☐ A사업장_20261028.xlsx` 같은 부모 **병합 그룹** 행에만 체크 표시를 보인다. 하위 시트(`11시` 등), 단독 파일, 인식 제외 파일에는 표시하지 않는다.
2. 최초 실행·정상 재분석 시 전부 **미체크**. 사용자는 부모 행의 텍스트 영역을 클릭하거나 키보드로 해당 그룹에 포커스하여 `Space`로 토글한다. 트리의 폴더 펼침/접기 화살표는 체크 상태에 영향을 주지 않는다.
3. `전체 선택`, `선택 해제` 버튼과 `선택 2 / 전체 3개 그룹` 상태 문구를 제공한다. 그룹 외 아이템은 선택 건수에 들어가지 않는다.
4. `선택 그룹 병합` 버튼은 체크 1개 이상이고 작업 중이 아닐 때만 활성화한다. 순서는 분석 결과의 그룹 순서로 유지한다. `전체 그룹 병합`은 체크 상태와 무관하게 모든 병합 가능 그룹을 처리한다.
5. 기존 Treeview의 행 포커스/하이라이트는 체크 여부와 **분리**된다. Ctrl/Shift 기반 다중 선택 상태는 작업 대상에 사용하지 않는다. 선택법 혼동을 줄이기 위해 단일 포커스 선택으로 변경한다.
6. 병합 중 체크 토글/전체 선택/선택 해제/재분석을 방지하고, 기존 작업 큐·오류·진행 표시·닫기 방지 동작은 그대로 유지한다.
7. 기존 병합 엔진 `classify.py`와 `merge.py`는 수정하지 않는다. `gui.py`, UI 테스트, README/릴리즈 노트 및 이 계획 문서만 변경한다.
8. 전체 선택/해제를 누르더라도 사용자가 체크한 내역이 실제 파일을 쓰거나 병합을 시작하지 않는다.

## 검증 기준

- 3개 그룹 중 A·C만 체크 후 선택 병합 → A·C 결과 파일 생성, B는 미생성; 체크 해제 후 선택 버튼 비활성.
- 전체 병합은 체크 상태와 무관하게 모든 그룹 처리.
- 하위 시트·단독/제외 파일 클릭·키보드로 그룹 상태를 변경하지 못한다.
- 클릭과 Space가 실제 Treeview 위젯에서 동작한다. 그룹의 접힘/펼침은 체크 표시를 바꾸지 않는다.
- 작업 중 상호작용을 잠그고 완료 시 UI 복구, 재분석 시 기존 체크 제거.
- 기존 전체 자동 테스트, Windows GUI 스모크 테스트, PyInstaller EXE 빌드 및 GitHub Release 확인.
