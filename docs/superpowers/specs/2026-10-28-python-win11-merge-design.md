# Windows 11 엑셀 시트 자동병합 — Python 설계

## 목적
Windows 11 사용자가 이름에 공통 사업장·날짜가 있고 시간만 다른 여러 `.xlsx` 파일(각각 정확히 1개의 시트)을 GUI에서 확인하고 1개의 `.xlsx`로 병합한다. 설치형 Python이 없어도 실행되는 EXE 배포를 목표로 한다.

## 인터페이스
- Python 3.12 + Tkinter GUI, 한국어 표시, 입력 폴더 지정, 그룹/시트 미리보기, 제외 사유, 선택 또는 전체 병합, 진행률, 로그, 결과 폴더 열기.
- 출력: `<선택폴더>/병합결과/<사업장>_<YYYYMMDD>.xlsx`.
- 동일 그룹 2개 이상의 엑셀 파일만 병합; 1개는 보류 목록 표시. 결과가 이미 존재하면 덮어쓰지 않고 건너뛴다.
- 시간은 `11시`, `09시30분`, `14-30`, `1430`, `오후2시`처럼 인식한다. 날짜는 `YYYYMMDD`, `YYYY-MM-DD`, `YYYY_MM_DD`, `YYYY.MM.DD` 형식을 인식한다.
- 사업장/기타 한정어는 날짜·시간을 제외한 나머지 파일명으로 엄격하게 분류한다. 불확실한 두 날짜/두 시간은 제외, 유사 문자열끼리 임의 병합 금지.
- 시트명은 시각(24시간제) 기준 `11시`, `14시30분` 등. 중복 시 `11시 (2)`처럼 수정. 원본 파일의 순서대로 시간순 정렬.

## 기술 선택
- 비교: (1) openpyxl: Excel 설치 불필요하지만 일부 도형/차트/고급 서식 손실 위험. (2) Microsoft Excel COM: Excel 설치 필요하지만 셀 서식과 시트 객체 복사 충실도 높음. **(2) 채택**.
- Python pywin32 + `DispatchEx("Excel.Application")`으로 분리된 백그라운드 Excel 프로세스. 열기 시 링크 갱신 방지, 매크로 비활성화, 원본 읽기 전용. 새 통합 문서에 원본 시트 복사, 임시 파일 저장·닫은 뒤 같은 폴더에서 이름 변경(원자적 완료 표시).
- Windows GUI thread는 Tkinter와 통신할 때 `queue.Queue`만 사용한다.
- Windows용 PyInstaller `--onefile --windowed`로 배포. Windows 빌드 환경이 없는 경우 GitHub Actions `windows-latest`의 빌드 절차 제공; 빌드되지 않은 Python 소스를 EXE로 속여 제공하지 않는다.

## 범위 제한/주의
- `.xlsx`만 병합하며 `.xls`, `.xlsm`, `.xlsb`는 제외 사유에 기록.
- 통합 문서당 시트가 정확히 하나가 아니거나 암호 보호/손상/형식 오류가 있으면 해당 그룹을 실패 처리하고 다음 그룹 진행.
- Excel 데스크톱 앱 설치 필요; 조직 보안 정책 우회 금지. 외부 통합 문서 참조나 데이터 연결은 원본 그대로 남을 수 있으므로 병합 결과 확인 권고.
- 사용자 원본 수정·삭제 금지. 출력 기존 파일 덮어쓰기 금지. 오작동에도 불완전한 최종 이름의 파일을 남기지 않는다.
