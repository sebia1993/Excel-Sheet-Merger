# Excel Sheet Merger — CSV·Excel → XLSX 시간별 시트 자동 병합

Windows 11용 한국어 GUI 프로그램입니다. 같은 **사업장 + 날짜**의 여러 CSV·Excel 파일(`.csv`, `.xlsx`, `.xlsm`, `.xls`)을 하나의 `.xlsx` 파일로 합치고, **원본 파일명 속 시간**을 시트 이름으로 사용합니다. CSV와 Excel 파일이 섞여 있어도 병합할 수 있습니다.

**Python 설치도, Microsoft Excel 설치도 필요하지 않습니다.** 실행 파일은 Python/Tkinter, ttkbootstrap, openpyxl, xlrd를 PyInstaller로 패키징합니다.

## v1.2 미니멀 업무형 화면

화이트/그린 컬러의 Windows 11 업무 도구 스타일을 적용했습니다. 기존 v1.2 디자인을 유지한 채 Excel 입력 지원을 추가했습니다. CSV 텍스트 처리와 기존 파일 보호 방식은 그대로입니다.

- 상단: **폴더 선택 → 파일 분석**. 선택하면 기존처럼 즉시 분석합니다.
- 요약 카드: **검색 파일 / 병합 그룹 / 단독 파일 / 제외 파일** 개수.
- 가운데: 넓은 계층형 **미리보기 표**. 병합 가능한 **그룹 행마다 ☐/☑ 체크박스**가 표시됩니다. 하위 시간별 시트는 내용 확인용이며, 체크 대상이 아닙니다.
- 그룹 선택: `전체 선택`, `선택 해제` 버튼 또는 그룹 행 클릭으로 복수 그룹을 체크할 수 있습니다. 키보드로 그룹 행에 포커스한 뒤 `Space`를 눌러도 체크가 전환됩니다. 왼쪽 펼침 화살표는 체크 상태를 변경하지 않습니다.
- 하단: **전체 그룹 병합**(녹색 주 버튼)은 체크 여부와 관계없이 모든 병합 가능 그룹을 처리합니다. **선택 그룹 병합**은 체크된 그룹만 처리하며, 체크가 없으면 비활성화됩니다. 기존 **결과 폴더 열기** 및 진행률도 유지합니다.
- **작업 기록 보기**는 기본으로 접혀 있습니다. 오류가 발생하면 자동으로 펼쳐집니다.
- 앱은 한국어 UI입니다. 기존 결과를 덮어쓰지 않으며, **같은 파일명이 이미 있으면 `(2)`, `(3)`...을 붙여 새 파일을 생성**합니다. CSV 텍스트 값은 변경 없이 보존합니다.

UI는 [ttkbootstrap](https://github.com/israel-dryer/ttkbootstrap)(MIT)의 기존 ttk 스타일 확장을 이용합니다. 실제 사용자는 별도 테마나 라이브러리를 설치하지 않아도 됩니다. Windows의 접근성 배율(100~150%) 및 실제 창 크기는 사용 PC에서 확인해 주세요.

## 병합 결과 예시

| 원본 파일 | 병합 결과 | 시트 이름 |
| --- | --- | --- |
| `A사업장_20261028_11시.csv` | `A사업장_20261028.xlsx` | `11시` |
| `A사업장_20261028_14시.xlsx` | `A사업장_20261028.xlsx` | `14시` |
| `A사업장_20261028_17시.xls` | `A사업장_20261028.xlsx` | `17시` |

CSV만 3개, Excel만 3개, 또는 **CSV와 Excel이 섞인 3개**도 모두 같은 방식으로 병합합니다. 결과 파일은 선택 폴더 아래 `병합결과`에 저장합니다. 사업장이나 날짜가 다르면 별도 파일로 만듭니다.

## EXE 사용 방법

1. [최신 Windows EXE 다운로드](https://github.com/sebia1993/Excel-Sheet-Merger/releases/latest/download/ExcelSheetMerger.exe) → **Assets**에서 `ExcelSheetMerger.exe`를 받습니다.
2. Windows 11에서 실행 후 **폴더 선택** → CSV·Excel 파일이 담긴 폴더 지정.
3. **파일 분석**으로 그룹, 결과 파일명, `11시` / `14시` / `17시` 시트명, 제외 사유를 미리 확인합니다.
4. 일부 그룹만 병합하려면 그룹 행의 **☐ 체크박스**를 선택하고 **선택 그룹 병합**을 클릭하세요. 모두 병합하려면 체크 여부와 관계없이 **전체 그룹 병합**을 클릭합니다.
5. `병합결과` 폴더에서 `.xlsx` 파일과 UTF-8 작업 기록을 확인합니다. 동일한 결과 파일명이 이미 있으면 완료 창에 안내가 나타나고 기존 파일명 → 새 파일명이 기록됩니다.

## 지원 형식과 제한 사항

- **지원 입력:** `.csv`, `.xlsx`, `.xlsm`, `.xls` (대소문자 구분 없음). `.xlsb` 등 다른 형식은 인식 제외 사유를 표시합니다.
- 일반 Excel은 **원본 파일당 시트가 정확히 1개**여야 합니다. 원본에 여러 시트가 있거나 파일이 손상된 경우 해당 **그룹 전체**를 실패 처리하고 다른 그룹 처리는 계속합니다.
- 날짜: `20261028`, `2026-10-28`, `2026_10_28`, `2026.10.28`.
- 시간: `11시`, `09시30분`, `14-30`, `1430`, `오전9시`, `오후2시` 등.
- 파일명에서 날짜 **하나**와 시간 **하나**를 인식할 수 있어야 하며, `최종`, `수정` 같은 접미사는 사업장 구분에 포함됩니다. 비슷하지만 다른 이름의 파일을 임의로 합치지 않습니다.
- 사업장명과 날짜가 동일한 파일을 묶고 시간을 오름차순 정렬합니다. 같은 시간에 원본이 2개 있으면 `11시`, `11시 (2)`로 이름을 구분합니다. 단독 파일 1개 그룹은 병합 보류합니다.
- CSV는 **UTF-8(BOM 포함), CP949/EUC-KR, UTF-16(BOM)** 등을 처리하며 쉼표·쌍따옴표·줄바꿈을 지원합니다. CSV의 모든 값은 **Excel 텍스트**로 저장해 `00123`, IP/MAC, `=SUM(...)` 같은 문자열이 자동 변환되지 않게 합니다.
- `.xlsx`·`.xlsm`은 숫자/날짜/문자열/수식/대표 셀 스타일·셀 병합·행/열 크기·틀고정을 가능한 범위에서 보존합니다. **차트·이미지·피벗 테이블·외부 연결·조건부 서식·수식 캐시는 완전 복제를 보장하지 않습니다.** 수식 중 원본 시트명을 직접 참조하는 수식은 시트명이 바뀌므로 사용자가 결과를 검증해야 합니다.
- `.xlsm`을 `.xlsx`로 변환할 때 매크로(VBA)는 제거됩니다. `.xls`는 **셀 값·날짜·불리언** 중심으로 변환하며 기존 셀 서식은 복사하지 않습니다. 기존 xls 수식은 마지막으로 계산된 값으로 읽힐 수 있습니다.
- **원본 CSV/Excel 파일은 수정하지 않습니다.** 결과 파일명이 중복되면 기존 결과를 덮어쓰지 않고 새 파일을 추가로 생성합니다. 예: `A사업장_20261028.xlsx` → `A사업장_20261028 (2).xlsx` → `A사업장_20261028 (3).xlsx`. 번호는 사용되지 않은 가장 작은 값부터 부여합니다.
- 이름 충돌은 GUI의 작업 기록과 완료 안내에 표시됩니다. 작업 기록에는 **원래 파일명 → 실제 생성 파일명**이 남습니다. 생성 중 오류가 나면 임시 출력 파일을 지웁니다. 다른 프로세스가 같은 이름을 동시에 생성해도 파일을 덮어쓰지 않고 다음 번호를 시도합니다.
- Excel 한계: 시트당 **1,048,576행 × 16,384열**. Excel 포함 그룹은 서식을 복사하기 위해 메모리를 더 사용하므로 대형 Excel 파일에서는 메모리 부족에 유의하세요.
- **Excel 설치가 필요하지 않습니다.** 완성된 XLSX를 열려면 Excel 또는 호환 뷰어가 필요합니다.

## 자동 EXE 빌드 및 Release

`main` 브랜치에 변경이 푸시되면 `.github/workflows/windows-exe.yml`이 Windows 러너에서 **테스트 → PyInstaller EXE 빌드 → PE 형식 검사 → SHA-256 생성 → GitHub Release 업로드**를 수행합니다. 성공 이후 [Releases](https://github.com/sebia1993/Excel-Sheet-Merger/releases/latest)에서 버전별 다운로드를 확인할 수 있습니다. 혼합 입력 지원 버전은 `v1.3.<워크플로 실행 번호>` 태그로 배포됩니다.

개발 PC에 Python 3.12가 설치되어 있다면 `build_windows.bat`로 로컬 빌드할 수 있습니다. 사용자 PC에는 Python을 설치할 필요가 없습니다.

## 개발과 테스트

- Python 3.12+, `openpyxl>=3.1.5`, `xlrd==2.0.2`, Tkinter, `ttkbootstrap==2.2.6`, PyInstaller.
- `python -m pip install -r requirements-build.txt` (개발/빌드 PC만)
- `python -m unittest discover -s tests -v`
- `python app.py`
- 주요 파일: `src/excel_sheet_merger/classify.py`(파일명 분류), `merge.py`(CSV·Excel 입력 및 XLSX 생성), `gui.py`(한국어 GUI), `ui_theme.py`(UI 디자인 토큰).

## 실제 환경 검증 범위

CSV·XLSX·XLSM 변환은 테스트 워크북으로 검증합니다. `.xls`는 테스트용 읽기 인터페이스를 통해 동작을 검증하되 실제 구형 Excel 파일에 대한 추가 실사용 테스트를 권장합니다. GitHub Actions에서 Windows용 EXE 패키징도 확인할 수 있습니다. **실제 회사 PC/VDI 정책, 백신 탐지, 특수 CSV 인코딩 및 대용량 처리**는 실사용 환경에서 추가 검증이 필요합니다. 코드 서명되지 않은 EXE는 회사 보안정책상 실행 제한될 수 있으니 정책을 준수하세요. Linux에서는 ttkbootstrap 설치가 불가능할 때 개발용 `clam` 스타일로 UI 스모크 테스트를 할 수 있지만, **Windows 릴리즈는 ttkbootstrap을 반드시 설치하고 포함**합니다.
